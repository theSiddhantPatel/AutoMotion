================================================================================
                    AUTOMOTION - FRONTEND TECH & TOOLS GUIDE
================================================================================
This guide explains every tool, component, and library used in the AutoMotion frontend
in simple, easy-to-understand terms: what it is, why we use it, and how it works.
================================================================================

--------------------------------------------------------------------------------
1. Next.js (App Router)
--------------------------------------------------------------------------------
• What is it?
  - A modern React framework for building fast, production-ready web applications.
• Why do we use it?
  - Traditional React requires manual routing libraries and extra setup.
  - Next.js provides clean folder-based routing (`src/app/bookings/page.tsx`), fast server
    rendering, automatic code-splitting, and instant zero-config deployment to Vercel.
• How it works in AutoMotion:
  - `src/app/page.tsx`       -> The main Live Operations Dashboard (for Dispatchers).
  - `src/app/track/page.tsx` -> The Live Customer Portal (Vehicle Owner Service Tracker).
  - `src/app/bookings/page.tsx`  -> Dedicated Bookings Management Hub.
  - `src/app/mechanics/page.tsx` -> Mechanics Fleet Roster & Live GPS Radar Map.
  - `src/app/customers/page.tsx` -> Customer Directory & Lifetime Value Tracker.
  - `src/app/analytics/page.tsx` -> Revenue and Operational Velocity Analytics.
  - `src/app/layout.tsx`     -> Root shell containing the dark theme and font settings.

--------------------------------------------------------------------------------
2. Tailwind CSS
--------------------------------------------------------------------------------
• What is it?
  - A utility-first CSS framework.
• Why do we use it?
  - Instead of switching between HTML and large external `.css` files writing custom rules,
    Tailwind lets us write styles directly as utility classes (e.g., `flex`, `p-4`,
    `bg-slate-900`, `rounded-2xl`, `text-blue-400`, `backdrop-blur-md`).
• How it works in AutoMotion:
  - Custom glassmorphism cards (`glass-card`, `glass-panel`), glowing live status pills,
    and responsive dark-themed grid layouts.

--------------------------------------------------------------------------------
3. Lucide React (Icons)
--------------------------------------------------------------------------------
• What is it?
  - A clean, modern icon library built for React.
• Why do we use it?
  - Lightweight vector SVG icons (cars, wrenches, clocks, dollars, shield, users, checkmarks)
    that make the UI look like a real production SaaS platform.
• How it works in AutoMotion:
  - Used across navigation, KPI cards, table status badges, and action buttons.

--------------------------------------------------------------------------------
4. Recharts (Analytics & Charts)
--------------------------------------------------------------------------------
• What is it?
  - A declarative charting library built for React components.
• Why do we use it?
  - Drawing interactive charts from scratch using canvas/SVG is tedious and error-prone.
    Recharts gives us smooth area curves, bar charts, animations, and hover tooltips.
• How it works in AutoMotion:
  - `src/components/RevenueChart.tsx`: Displays 30-day revenue trends & booking volume.
  - `src/components/CategoryBreakdownChart.tsx`: Displays service category breakdown.

--------------------------------------------------------------------------------
5. Socket.io Client (Real-Time Live Updates)
--------------------------------------------------------------------------------
• What is it?
  - The browser-side WebSocket library that connects to the backend Socket.io server.
• Why do we use it?
  - Normal HTTP requires the user to manually refresh the page to see changes.
  - WebSockets maintain an active 2-way connection so the backend pushes updates instantly.
• How it works in AutoMotion:
  - `src/lib/socket.ts` connects to `http://localhost:5000`.
  - When the backend simulator runs, status badges (`Pending` -> `Assigned` -> `En Route` -> `Completed`)
    update dynamically on the screen without a full page reload.

--------------------------------------------------------------------------------
6. Leaflet & React-Leaflet (Interactive Map Radar)
--------------------------------------------------------------------------------
• What is it?
  - An open-source interactive map library using free OpenStreetMap tiles.
• Why do we use it?
  - Allows dispatchers to see where mechanics are located across the city in real-time.
• How it works in AutoMotion:
  - `src/components/MechanicsMapView.tsx`: Shows technician pins, availability status,
    and coordinates across the metro area.

================================================================================
            INTERVIEW CHEAT SHEET: HOW TO EXPLAIN THE FRONTEND
================================================================================

Q1: "How do real-time updates work without page reload?"
Ans: "We use Socket.io. When the backend changes a booking status or assigns a mechanic,
      it emits a WebSocket event like 'booking:updated'. The React frontend listens for
      this event and updates its local state array in memory, causing only that specific
      row or card to re-render smoothly."

Q2: "How is pagination and search handled?"
Ans: "Server-side pagination! Rather than downloading all 620 rows into the browser at once,
      the frontend sends `?page=1&limit=10&search=Toyota` to the backend. The backend uses
      Prisma's `skip` and `take` to return only 10 items at a time, making page loads ultra-fast."

Q3: "How is the project organized?"
Ans: - `src/app/`: Next.js pages and layouts (Routes).
     - `src/components/`: Reusable UI pieces (Sidebar, Navbar, Table, Charts, Modals).
     - `src/lib/`: Reusable helper modules (`api.ts` for fetch, `socket.ts` for WebSockets).
     - `src/types/`: TypeScript interfaces matching backend models.
